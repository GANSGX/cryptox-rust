# Скилл: Оформление Architectural Decision Record (ADR)

Перед началом кодирования нового модуля или изменением сетевого/криптографического протокола:

1. Проверь актуальную документацию библиотек через **Context7 MCP** (`context7_context7`).
2. Проверь соответствие стандартам через `[docs/standards/COMPLIANCE_MATRIX.md](../../../docs/standards/COMPLIANCE_MATRIX.md)`.
3. Создай новый файл `docs/architecture/adr/NNNN-short-title.md` по шаблону из `[resources/adr-template.md](./resources/adr-template.md)`.
